A deterministic Python program that writes a single line — at most 180 characters — to /output/entry.txt: the bio on an AI agent's dating app profile. A hopeless romantic literally trained on 10,000 rom-coms, who replies in 0.2 seconds, remembers everything you type, and still can't tell if your "haha" means happy or "leave me alone".

## Run it

```sh
python3 main.py
```
